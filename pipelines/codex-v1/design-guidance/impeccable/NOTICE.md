# Impeccable design-guidance adaptation

This text-only adaptation includes guidance derived from Impeccable by Paul Bakaus
(https://github.com/pbakaus/impeccable), pinned at commit
b4bff1626c344067788c2679f048a20057c7cc5a, under the Apache License 2.0.

The five guidance documents have been modified for this repository. They retain
design and usability principles while replacing upstream tooling, orchestration,
numeric scoring, interactive approval workflows and mandatory aesthetic rules
with this pipeline's existing contracts. See SOURCE.json for exact source paths,
upstream blob IDs and local file hashes.

No upstream executable, launcher, hook manifest, agent definition or account
integration is included.

The upstream NOTICE.md is reproduced below for attribution completeness.
Its native platform reference files are not included in this adaptation.
