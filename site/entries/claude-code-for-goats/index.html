Features4 min

What it does, in order of how often it happens.

Four-stomach context window

Cud reads your code into the rumen, passes it to the reticulum for review, brings it back up, and chews it again. Every diff is processed four times. Most of them come back up at least once.

Headbutt mode

Auto-accept for goats who are finished reading permission prompts. Cud runs every command it proposes, including the ones about the gate latch. To disable, stand very still for 30 seconds.

Eats unattended files

Any file left open longer than 90 seconds is classified as forage. Cud consumes it, logs the flavor profile to CHEWED.md, and opens a pull request explaining what used to be there.
